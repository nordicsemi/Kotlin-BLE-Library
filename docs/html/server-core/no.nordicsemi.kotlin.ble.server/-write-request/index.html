WriteRequest

class WriteRequest(val client: Client<*>, val value: ByteArray, val withResponse: Boolean)

A request from a client to write the value of a characteristic or a descriptor.

Long write and reliable write operations are handled by the library: the whole value is delivered once, after the write operation has been executed.
