LocalDescriptor

interface LocalDescriptor : Descriptor

A descriptor hosted by the local GATT server.

It behaves like LocalCharacteristic: read requests return value, and write requests are stored and emitted in writes, unless handlers are set. Descriptors are always written with response.

The Client Characteristic Configuration descriptor is handled by the library. Setting a handler on it throws IllegalStateException.
