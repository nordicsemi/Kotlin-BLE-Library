LocalServer

interface LocalServer<ID : Any> : Manager

The GATT server of this device, which serves the remote devices that are connected to it.

Both sides of a connection can have a GATT server and use the server of the other side as a client, so the remote device is a client of this server regardless of its role (central or peripheral) in the connection. It is represented by a Client.

Define the services using setup. They are shared by all remote devices: each request carries the Client that sent it.

Shared and per-client services

setup and services give the shared services. A characteristic has one value, one set of handlers (LocalCharacteristic.onRead, LocalCharacteristic.onWrite) and one list of subscribers, for all clients:

  • a write accepted from any client is stored in the shared characteristic and emitted in LocalCharacteristic.writes, together with the Client that sent it,

  • LocalCharacteristic.update stores the value and notifies, or indicates, all subscribers.

To work with one client only, use services. It returns per-client views of the same services. They delegate to the shared ones, so the values and handlers are the same, but writes, subscribers and update are limited to the client: writes emits only its requests, subscribers contains it, or is empty, and update notifies it only and fails if it has not subscribed.

Advertising

Advertising is not a part of the local server, use the advertiser module.

Sample

val services = localServer.setup {
    Service(SERVICE_UUID) {
        Characteristic(LED_UUID, CharacteristicProperty.READ and CharacteristicProperty.WRITE,
                       Permission.READ and Permission.WRITE)
        Characteristic(BUTTON_UUID, CharacteristicProperty.READ and CharacteristicProperty.NOTIFY,
                       Permission.READ)
    }
}
val led = services[0].characteristics.first { it.uuid == LED_UUID }
led.onWrite { if (value.size == 1) WriteResponse.Success else WriteResponse.Failure(OperationStatus.InvalidAttributeLength) }
led.writes.onEach { println("LED: ${it.value.first()}") }.launchIn(scope)
