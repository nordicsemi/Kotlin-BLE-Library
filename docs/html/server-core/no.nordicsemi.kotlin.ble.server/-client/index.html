Client

interface Client<ID : Any> : Peer<ID>

A remote device that is using the local GATT server, that is a client of this server.

It is not necessarily the central of the connection: both sides can have a GATT server and use the server of the other side.

A client is known to the LocalServer when it sends a request or subscribes to a characteristic. Platform-specific modules may provide more information, like the connection state, MTU or PHY.
