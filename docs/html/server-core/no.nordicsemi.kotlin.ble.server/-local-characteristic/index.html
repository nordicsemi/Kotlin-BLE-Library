LocalCharacteristic

interface LocalCharacteristic : Characteristic<LocalDescriptor>

A characteristic hosted by the local GATT server, which remote clients can read, write to and subscribe to.

By default, read requests return value, and write requests are stored and emitted in writes. Use onRead and onWrite to handle requests dynamically, for example to validate data or to return a different value for each client.
