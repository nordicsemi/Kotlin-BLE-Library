LocalProfile

sealed class LocalProfile(localServiceUuids: List<Uuid>, name: String? = null) : Profile<LocalServer<*>, Nothing, LocalService>

A profile that uses the local services of a LocalServer only.

The profile is registered with LocalServer.profile. The services are defined by the application, using LocalServer.setup. The profile starts when all of its services exist, and it is cancelled and started again when the services are replaced.

Types of profiles

Extend one of the classes below. Each of them has a full example.

  • Simple - a profile based on a single local service,

  • MultiService - a profile based on multiple local services, all of which are required.

A profile that also uses the services of a remote device extends the Profile.WithLocalServices of the client instead.

Parameters

localServiceUuids

The UUIDs of the local services the profile needs.

name

The name of the profile. This is for convenience, used only in logging.
