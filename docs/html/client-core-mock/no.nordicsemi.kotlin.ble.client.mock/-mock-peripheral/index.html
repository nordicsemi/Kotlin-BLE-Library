MockPeripheral

interface MockPeripheral

A simulated peripheral, as seen by its PeripheralSpecEventHandler.

It is the peripheral for which the event was called. The handler can use it to make the peripheral do something, e.g. disconnect, send a notification, or change its services, and to check its state.

The behavior is defined in PeripheralSpec, which implements this interface. See the documentation there for the details of each method.
