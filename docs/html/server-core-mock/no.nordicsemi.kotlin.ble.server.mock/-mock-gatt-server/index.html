MockGattServer

open class MockGattServer<ID : Any>(val state: StateFlow<Manager.State> = MutableStateFlow(Manager.State.POWERED_ON)) : GattServer

A simulated platform layer of the local GATT server.

It is used by the shared LocalServerImpl instead of a native GATT server. It does not contain any logic of the GATT server itself: it only stores the definitions of the services, turns actions of simulated clients (MockClient) into GattServerEvents and delivers the responses and notifications back to them.

Requests of simulated clients suspend until the server calls respond. Notifications and indications are delivered immediately, and indications are confirmed automatically.

state

The state of Bluetooth on the simulated device. Defaults to always powered on.
