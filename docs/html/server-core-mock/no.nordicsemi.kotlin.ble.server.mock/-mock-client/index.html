MockClient

abstract class MockClient<ID : Any>(val identifier: ID, gattServer: MockGattServer<ID>, val maxMtu: Int = ATT_MTU_MAX, environment: Environment? = null, scope: CoroutineScope? = null) : Client<ID>

A simulated client device, which talks to a MockGattServer.

A client has to be connected using connect. Then, server is the GATT server of the phone as the client sees it, with the same API as a peripheral has in the client modules: the services are discovered, and the characteristics are read, written and subscribed to, using the long read, long write and reliable write procedures when needed.

All operations complete immediately, without any delays, when the server responds. They work with the virtual time of runTest. Requests are executed one at a time, like in a real ATT bearer.

The requests identifying attributes by their instanceId, like findCharacteristic, are the low-level transport of the mock modules, see LowLevelMockApi.

This class is meant to be extended by platform-specific mock clients, which also implement the platform-specific Client interface.
