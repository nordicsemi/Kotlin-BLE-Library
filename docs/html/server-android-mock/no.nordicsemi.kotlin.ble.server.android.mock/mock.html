fun LocalServer.Factory.mock(environment: MockAndroidEnvironment = LatestApi(), scope: CoroutineScope): MockLocalServer

Creates a mock implementation of a LocalServer, which hosts a simulated GATT server.

Use MockLocalServer.simulateClient to simulate clients that connect to the server and send requests to it.

Background work of the manager, like handling of requests, runs in the given scope. A scope backed by a test dispatcher, e.g. backgroundScope of runTest, makes it follow the test scheduler and its virtual time.

Parameters

environment

The environment to use for the mock, defaults to the latest supported API. Bluetooth state and permissions are taken from it.

scope

The coroutine scope.
