MockAndroidClient

class MockAndroidClient : MockClient<String> , Client

A simulated Android client, created using MockLocalServer.simulateClient.

It is the Client seen by the app (in requests and in LocalServer.connectedClients), and at the same time a MockClient, which is used to simulate what the client does: connecting, using the services (server), and changing the MTU, PHY and connection parameters.

val client = localServer.simulateClient()
client.connect()
client.simulateMtuChange(185)
val led = client.server.services(listOf(SERVICE_UUID))
    .filterIsInstance<RemoteServices.Discovered>()
    .first { it.services.isNotEmpty() }
    .services.single().characteristics.first { it.uuid == LED_UUID }
led.write(byteArrayOf(1), WriteType.WITH_RESPONSE)
