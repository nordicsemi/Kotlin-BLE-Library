Profile

abstract class Profile<in P : Any, R : PrimaryService<*>, L : PrimaryService<*>>(val requiredServiceUuids: List<Uuid> = emptyList(), val optionalServiceUuids: List<Uuid> = emptyList(), val localServiceUuids: List<Uuid> = emptyList(), val name: String? = null)

A Bluetooth LE profile, which separates the GATT services from the application logic.

A profile can use services of both sides of the connection: the services of the other device, which are discovered after connecting (R), and the services of this device, which were defined by the application (L). For example, the Proximity Profile uses the Link Loss and Immediate Alert services of the other device, and offers its own Link Loss and Immediate Alert services. Profiles using the services of one side only use Nothing as the type of the other one.

The profile is registered on a manager, which calls prepare when all the services were found, and then initialize to start it.

Local services are not added by the profile. They are defined by the application when it sets up the server. The profile only receives them, when they are available.

Type Parameters

P

The type of the object the profile is attached to, for example a peripheral.

R

The type of the services of the other device.

L

The type of the local services.
