BondingFailure

enum BondingFailure : Enum<BondingFailure>

The reason why bonding of a simulated peripheral failed.

The client is told the matching reason, and the phone terminates the link a few seconds later. A peripheral that terminates the link itself after a failed bonding can be simulated by calling PeripheralSpec.simulateDisconnection().

Note: Most phones report all the failures, except REJECTED on some, with the same reason (the library reports it as AuthenticationFailed), and the exact reason differs between Android versions. Use REJECTED to emulate a real refusal of the peripheral. The other failures allow testing how the app reacts to the other reasons, which may be reported by phones in the future.

CANCELLED and WRONG_PIN only make sense for pairing that requires user interaction. AUTH_FAILED is the same as WRONG_PIN, but reads better when the simulated peripheral does not use a PIN.
